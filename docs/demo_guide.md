# 预测窗口 · 测试数据说明

## 三个文件，按需选用

| 文件 | 列 | 用途 |
|---|---|---|
| `demo_full.csv` | 10 列（含实测值、预期、场景说明）| **推荐**：边看结果边对照 |
| `demo.csv` | 6 列（接口真正读取的）| 干净地跑流程 |
| `demo_smiles_only.csv` | 2 列（ID + SMILES）| 测最保守路径 |

> 接口只读 6 列：`ID / SMILES / Strain / cfuGroup / Medium / CyclizationType`。
> 其余列（`实测MIC_uM`、`定性概率_参考`、`场景`、`预期`）**仅供人眼对照，不影响预测**。

---

## 怎么用

### 图形界面（推荐）

```bash
python cpamp_gui.py
```

1. 首页点「预测」
2. 点「导入文件…」，选 `demo.csv`
3. （可选）改测定条件 —— 但**注意**：界面上的条件是"全局"的，会覆盖所有行。
   想逐行不同，就直接用命令行。
4. 点「开始预测」
5. 点结果里任意一行，下方明细面板会显示两个通道的完整依据

### 命令行（能保留每行自己的条件）

```bash
python cpamp_tool.py predict -i demo.csv -o 结果.csv
```

`--detail` 可输出完整 39 列（含校准阳性率、Wilson 区间、σ、四轴说明）。

## 三个值得注意的现象

### ① T09：加的是"永久留出"的菌株

`Escherichia coli ATCC 25922` 是训练时被**永久留出的 4 株**之一，
所以它会走"未知菌株"路径 —— 这不是 bug，而是设计好的泛化测试。

### ② T10：不填环化类型会明显收缩

对比 T05（同菌株、类型 AMD）：T05 预测 12.6 µM，T10 预测 2.35 µM。
因为不填类型 → 按"新类型"处理 → 乘以预注册的收缩系数 **0.51**。

**这就是为什么界面上把「环化类型」标成影响最大的字段。**

### ③ T12：不给菌株就出不了定量值

定量模型需要「菌株上下文」6 维特征（革兰氏分类、菌株编号、该株中位 MIC）。
没有菌株 → 这 6 维无法构造 → 定量输出 NaN，只保留定性通道。

**要给定量结果，至少填一个菌株。**

## 自己造测试数据

最小要求：

```csv
SMILES
CC(C)C[C@@H]1NC(=O)...
```

推荐再加 `Strain`、`CyclizationType` 两列，效果最好。

**列名容错**：大小写不敏感，也认中文 ——
`SMILES / 结构 / 分子`、`Strain / 菌株`、`cfuGroup / cfu`、`Medium / 培养基`、`CyclizationType / 环化`。

**编码**：UTF-8 / GBK / GB18030 都能读（Excel 另存为 CSV 默认 GBK，没问题）。

```bash
python cpamp_lib/268_make_test_csv_v2.py
```

所以每次重跑得到的肽可能不同，但结构一致。
