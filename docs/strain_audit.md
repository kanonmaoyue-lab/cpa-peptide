# 菌株训练支撑度审计

> 问题：预测界面下拉里的 155 株，是否都真的训练到了？有没有"只有标签、没有预测能力"的？

## 结论

**155 株全部有训练数据**（每株 30–983 对，不存在"空标签"的菌株）。
**但预测能力差异很大** —— 这是需要如实告知用户的。

| 判定 | 株数 | 占比 | 样本合计 | 口径 |
|---|---:|---:|---:|---|
| **充分** | 81 | 52.3% | 9 511 | ≥30 条肽 且 OOF R² ≥ 0.4 |
| **可用** | 36 | 23.2% | 2 746 | ≥10 条肽 且 R² ≥ 0.2 |
| **弱** | 38 | 24.5% | 2 196 | 其余 |
| 无 | 0 | 0% | 0 | — |

其中 **18 株的 OOF R² < 0**（854 对，占 5.9%）——
意思是**对该菌株的预测还不如直接取全体均值**。

## 已做的修正

原来「信赖等级」只看"菌株是否在训练集内"，**R² = −0.33 的菌株也会判「高」**。现已修正：

| 该株判定 | 等级处理 | 「说明」列追加 |
|---|---|---|
| 充分 | 不变 | 无 |
| 可用 | 不变 | 该菌株 N 对样本、R²=+0.xx |
| 弱 | **降 1 级** | 该菌株仅 N 对样本、R²=+0.xx，把握偏低 |
| R² < 0 | **降 2 级**（通常落到「低」）| 该菌株 OOF R²=−0.xx（不如取均值），仅供定性参考 |

界面的菌株下拉也带上了标签：`Pseudomonas aeruginosa ATCC 27853 · 983对·充分`

## 写论文时怎么表述

不要写"155 株全部可靠"，应写：

> 模型覆盖 155 个菌株，其中 81 株（52.3%，占样本 65.8%）的留出预测
> R² ≥ 0.4；38 株（24.5%）受样本量限制预测力偏弱，其中 18 株
> R² < 0（占样本 5.9%）。系统按菌株支撑度自动下调信赖等级，
> 对 R² < 0 的菌株仅提供定性参考。
