## 1 为什么需要这一步

此前的状态：

| 项目 | 状态 |
|---|---|
| 论文报告的最终配置 | `(F2D + cfuGroup) ⊕ ESM(0.35)`，同分布 R² **0.6611** |
| 实际部署的模型 | `artifacts/expanded/expanded_models.pkl`（**2026-10-14**），R² **0.6448** |

**原因**：所有改进（ESM 融合、cfu、分区校准、区间）都在**交叉验证评估脚本**里实现——
每折训练一个模型、算出 OOF、报指标、**模型丢弃**。
没有任何脚本在"全部数据"上训练过含 cfu 与 ESM 的最终模型并保存。

⇒ 论文报的是**评估数字**，部署加载的是**两周前的旧模型**。

## 3 推理接口

```python
from cpamp_predict_v2 import predict
import pandas as pd

df = pd.DataFrame([{
    "SMILES": "CC(C)C[C@@H]1NC(=O)...",
    "Seq": "GIGKFLHSAKKFGKAFVGEIMNS",   # 可选
    "Strain": "Escherichia coli K-12",  # 可选；缺失则只输出定性
    "cfuGroup": 2,                      # 可选；0–4，对应 <1E4 … >1E7
    "Medium": "MHB",                    # 可选
    "CyclizationType": "DSB",           # 可选；缺失视为未知
}])
r = predict(df, use_esm=True, calibrate=True)
```

| 列 | 含义 |
|---|---|
| `定量_log10uM` / `定量_uM` | 点预测 |
| `定量_uM_low90` / `定量_uM_high90` | **90% 预测区间** |
| `σ_log10` | 所用区间宽度 |

## 4 三个机制的对应关系

### 4.1 cfu 与条件（§4.10）

- cfu 以 **cfuGroup 5 档序数**进入主模型（不是连续 log 值）
- 理由：连续值编码在 LOCTO 上为负（−0.0048），分组序数不退化（+0.0018）
- **cfu 对点预测的增益仅 +0.0035**，其主要作用在下面两节

### 4.2 适用域（§4.11）

四轴共同决定 `信赖等级`：

| 轴 | 判据 |
|---|---|
| 菌株 | 是否在 155 株训练集内 |
| 环化类型 | 是否在 18 种训练类型内 |
| 结构 | 与训练集最大 Tanimoto ≥ 0.7 |
| 条件 | 培养基与 cfu 是否落在标准药敏区间 |

规则：全部满足 → **高**；违反 1 项 → **中**；违反 ≥2 项 → **低**；未指定菌株 → **仅定性**。

实证依据：标准条件 R² 0.6928 vs 非标准 0.5904（Δ +0.1024）。

### 4.3 预测区间（§4.12）

σ 按两轴查表（来自 OOF 残差）：

| novelty | 标准条件 | 非标准 |
|---|---:|---:|
| known（同分布）| 0.4919 | 0.5587 |
| scaf（新骨架 / 新菌株）| 0.6001 | 0.6363 |
| locto（新环化类型）| 0.8893 | 0.8727 |

90% 区间 = `10^(ŷ ± 1.645·σ)`。

**实测价值**：常数 σ 会使标准条件过度保守（覆盖 0.916）、非标准过度乐观（0.888）；
按条件取 σ 后两者同时回到 0.902，**平均宽度仅变 −0.3%**。

### 4.4 分区校准（§4.5.5）

环化类型未在训练集出现时，预测乘 **k = 0.51**（预注册，由 k* = ρσ_y/σ_p 推出，非测试集调参）。

## 5 已知限制

| 限制 | 说明 |
|---|---|
| ESM 需联网或本地缓存 | 已设 `HF_HOME` 与离线模式；不可用时自动回退主模型并标注 |
| 新菌株的 σ 为保守估计 | 缺少"仅新菌株"的隔离评估；暂按 scaf 档处理 |
| 未指定菌株 | 只输出定性通道，不给定量 |
| 区间基于正态假设 | 残差近似对称，但重尾下偏窄 |
