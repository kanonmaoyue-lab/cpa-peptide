# 双通道环肽抗菌活性预测

一个可标注学习的环肽 MIC 预测系统：用分子结构预测抗菌活性，遇到训练集里没有的成环化学时，可用少量自有标注重训，把该类型从"不可用"变成"可用"。

---

## 1 功能

| 命令 | 用途 | 耗时 |
|---|---|---|
| `predict` | 输入 SMILES，输出 MIC 点预测 + 90% 区间 + 信赖等级 | 秒级 |
| `rank` | 批量预测后按活性排序，给出**合成优先级**与富集证据 | 秒级 |
| `check` | 用已有实测数据诊断模型偏差 | 秒级 |
| `finetune` | 把标注并入训练集**重训**，生成专属模型 | 3–8 分钟 |

图形界面（`start.bat`）提供同样的四项功能：预测页多一个「**排序指导**」按钮，
点一下即按预测活性重排表格并给出优先级分档与可信度说明。

## 2 性能

**定量通道**（同分布，n = 14 453 对）

| 指标 | 值 |
|---|---|
| R² | **0.6616** |
| MAE | 0.3765 log₁₀ |
| Pearson / Spearman | 0.8139 / 0.7878 |
| ±1 log 命中率 | 93.2% |

> 表中为 3 seed 集成预测的数值。逐 seed 单独计算的 R² 为 **0.6587 ± 0.0008**（n = 3），即随机种子对结论无实质影响；集成值略高于逐 seed 均值，差值即种子平均的降噪收益。

**定性通道**（5 类活性）：平均 AUROC **0.9427**

**六协议梯度**

| 协议 | R² |
|---|---:|
| 同分布肽簇 5 折 | 0.6616 |
| 未见骨架 | 0.5281 |
| 未见成环化学 | 0.0215 |
| 跨菌株外部（零先验） | 0.6339 |
| 留一文献 | 0.4629 |
| 前瞻时间切分 | **0.3201**（最接近真实部署）|

跨菌株外部口径（0.6339）与同类公开模型 tsAMP（0.634）持平。

### 2.1 排序与富集（真实部署口径）

前瞻时间切分下绝对 R² 只有 0.3201，但**排序**依然可用——这才是本工具的主要用法。
若只看类型与菌株均已知的子集（n = 6 887，占 87.0%），R² 为 0.3255、ρ = 0.5363，富集更强（EF₁₀ = 2.58）。

| 指标（前 10%） | MIC ≤ 4 µM | MIC ≤ 1 µM |
|---|---:|---:|
| 基础阳性率 | 33.0% | 13.5% |
| 本模型 **EF₁₀** | **2.42** | **4.00** |
| 对照：按结构相似度排序 | 1.07（≈随机） | 1.14 |
| 对照：按菌株中位值排序 | 1.48 | 2.00 |
| 理论上限（1/基础率） | 3.03 | 7.42 |
| 前 10% 召回率 | 24.2% | 39.9% |

读法三条：

1. **富集不是相似度伪影**——近邻 Tanimoto 中位高达 0.958，但只按相似度排序等于随机；
   富集来自模型学到的信号。
2. **2.42 已达上限的 80%**，因为基础率本就很高（33%），天花板只有 3.03 倍；
   不要与低基础率（1–5%）场景下的 EF 直接比大小。
3. **召回有限**：前 10% 只覆盖 24–40% 的真实高活性分子。它是「先做哪几条」的指南，
   不是「只做这几条」的许可。

> ①②③⑥ 为 3 seed 集成值，逐 seed 标准差分别为 0.0008 / 0.0007 / 0.0022 / 0.0067；④⑤ 为单次固定划分，无种子级重复，故不给 SD。

## 3 核心特性

**① 条件信息比表征复杂度更重要**
6 维菌株上下文带来 +0.2084 的 R² 提升；而把 2 048 维指纹扩到 2 331 维多视图只值 +0.0233。
表征确实已接近饱和，但两种口径的绝对值不同、不可混用：单特征块口径下 Morgan 单独 0.575、全部特征 0.555（论文表 4）；递进消融口径下 Morgan 单独 0.4131、全特征 0.4364（论文表 3）。两者共同支持的结论只有一个——把指纹扩到 2 331 维几乎没有增益。

**② 融合方式本身是独立变量**
同一 ESM-2 嵌入，特征级早期融合（直接拼接）为 −0.0094、预测级晚期融合为 +0.0128，0.022 的差异完全由融合方式造成（Wilcoxon 符号秩检验 p = 2.2×10⁻²，n = 14 453）。
机制有两层：① 贪心分裂在候选切分点上偏向稠密连续特征，离散指纹被稀释；② 晚期融合是异质模型集成，两个基学习器各自在最优特征空间收敛后再线性组合，避免互相干扰。

**③ 双通道输出，两种不确定度不通用**
定量给 MIC 的 90% 区间（预测误差尺度）；定性给每类活性的校准阳性率与 Wilson 95% 区间（概率的可靠性）。二者含义不同，不可互换。

**④ 标注学习必须重训，不能在推理端平移**
实测"只估偏移量再加回去"只能恢复 19–42% 的收益。

| 新增标注 | 该类型 R² |
|---:|---:|
| 0 | 0.0215（不可用）|
| 10 | 0.147 |
| 25 | 0.248 |
| 50 | 0.334 |

**⑤ 剩余误差不是「模型容量不够」，而是信息缺失**
由重复测定噪声估计的可解释上限为 **R²_max = 0.7975**；同分布 0.6616 与之相差 0.14，
主要被未记录的跨文献批次效应（终点判读、板吸附、稀释梯度）与缺失变量占据，
继续加容量/加数据的收益有限。

**⑥ cfu 字段的作用限于插值**
补入接种量字段后同分布 +0.0040、未见骨架 +0.0028，但未见成环化学 −0.0022。它的价值在适用域与区间校准，不在精度。

```bash
python -m venv .venv

# .venv/bin/pip install -r requirements.txt        # Linux / macOS
```

## 5 快速开始

**预测**

```bash
python cpamp_tool.py predict -i my_peptides.csv -o result.csv
```

输入最少只需两列：`ID, SMILES`。加上 `Strain / cfuGroup / Medium / CyclizationType` 可缩小预测区间、提高信赖等级。

**输出**（默认精简 10 列）

`ID, 定量_uM, 定量区间下限/上限, 定性各目标概率, 判定`

判定规则：校准阳性率 ≥ 0.5 判为阳性，并满足生物学约束（总抗菌 = 抗细菌 ∪ 革兰阳性 ∪ 革兰阴性）。

**排序指导（Hit-to-Lead 优先级）**

```bash
python cpamp_tool.py rank -i candidates.csv -o ranked.csv --save-notes
```

输出比 predict 多两列：优先级（1..N）与 建议（优先合成 / 备选 / 低优先 / 无定量值），
并在终端打印这段排序的可信度与使用边界。--top 0.25 可调整「优先合成」的比例；
--save-notes 会同时写一份 *_说明.txt，便于随结果一起存档。

判定优先级用**定量点预测升序**；若整批都没给菌株（无定量值），自动退化为按定性概率降序，
并在结论条中注明。
**诊断偏差**

```bash
python cpamp_tool.py check -l my_labels.csv
```

**标注学习**

```bash
python cpamp_tool.py finetune -l my_labels.csv -o my_model.pkl
python cpamp_tool.py predict -i new.csv --base my_model.pkl
```

标注文件至少需要：`SMILES, Strain, MIC_uM`（可选 `CyclizationType`）。

**模型选择与记忆（界面）**

窗口右上角有一个模型下拉条，按修改时间倒序列出 `models/` 下所有 `*.pkl`：

```
finetuned_20261117_205600.pkl  ·  11-17 20:56  ·  54MB
finetuned_bundle.pkl           ·  11-17 14:22  ·  54MB
final_bundle.pkl               ·  基础模型      ·  54MB
```

- 在「标注学习」页导入标注并完成后，新模型会自动生成、自动选中
- 每次重训写入 `models/finetuned_YYYYmmdd_HHMMSS.pkl`，**不覆盖历史**
- 随时可在下拉条里切回任一旧模型或基础模型
- 选择写入 `models/active_model.txt`，**重启窗口后保持**
- 命令行 `predict / rank / check` 不带 `--base` 时也遵循这份记录

## 6 适用域与局限

**可以用**：已知化学型 + 已知或同组菌株的活性定量；标准肉汤微量稀释条件（MHB/CAMHB，10⁴–10⁷ CFU/mL）内 R² ≈ 0.69、±1 log 94.3%。

**不适用**：

| 情形 | 表现 |
|---|---|
| 全新成环化学、零标注 | R² = 0.0215，即使最优校准也仅 0.0395 → 需 ≥10 条标注重训 |
| 全新肽骨架 | R² = −0.1127，无支撑 |
| 分档决策（敏感/耐药）| 不建议，应使用区间而非单点 |

**但适合做富集排序**。在前瞻时间切分（最接近真实部署）上，绝对 R² 仅 0.3201，Spearman ρ 仍有 0.5348。按预测值取前 10% 时，实测 MIC ≤ 1 µM 的分子占 53.9%（全测试集基础率 13.5%），**富集因子 EF₁₀ = 4.00**；以 MIC ≤ 4 µM 为判据时 EF₁₀ = 2.42。按预测值五等分，各组实测中位 log₁₀(MIC/µM) 依次为 0.09 / 0.79 / 1.01 / 1.30 / 1.63。
⇒ 模型的定位是**虚拟筛选的优先级排序工具**，不是绝对 MIC 的决策工具。

**菌株支撑度**：覆盖 155 株

| 判定 | 株数 | 占比 |
|---|---:|---:|
| 充分（R² ≥ 0.4）| 81 | 52.3% |
| 可用（R² ≥ 0.2）| 36 | 23.2% |
| 弱 | 38 | 24.5% |
| 其中 R² < 0 | 18 | 11.6% |

对 R² < 0 的菌株，系统自动把信赖等级下调两级并注明"仅供定性参考"。
详见 [docs/strain_audit.md](docs/strain_audit.md)。

## 7 模型结构

| 通道 | 输入 | 模型 | 融合 |
|---|---|---|---|
| 定量 | 2 331 描述符 + cfu 2 + 菌株上下文 6 = **2 339 维** | LightGBM × 3 seeds | 与冻结 ESM-2（960 维）预测级融合，w = 0.35 |
| 定性 | 2 277 描述符 + 目标编码 5 = **2 282 维** | LightGBM 统一模型（1 个替代原 5 个）| w = 0.50 |

LightGBM 超参：600 棵树、63 叶、学习率 0.05、最小叶样本 15、列采样 0.7、行采样 0.8。

**不确定度**：90% 区间 = `10^(ŷ ± 1.645 σ)`，σ 由「新颖性 × 测定条件」两轴查表给出（同分布 0.49 / 新骨架 0.60 / 新成环 0.87）。
