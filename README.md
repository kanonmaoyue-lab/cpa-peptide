# Cyclic Peptide Activity Predictor

环肽抗菌活性预测工具。**核心特点：遇到新的成环化学时，可以用少量自有标注重训，把该类型从"不可用"变成"可用"。**

---

## 1 这个工具能做三件事

| 命令 | 用途 | 耗时 |
|---|---|---|
| `predict` | 输入 SMILES，输出 MIC 点预测 + 90% 区间 + 信赖等级 | 秒级 |
| `check` | 用你手上已有的实测数据，诊断模型偏差有多大 | 秒级 |
| `finetune` | 把标注并入训练集**重训**，生成专属模型 | 约 3–8 分钟 |

---

## 2 为什么需要 finetune

遇到**训练集里没有的成环化学类型**时，零标注的 R² 只有 **0.02**，完全不可用。

实测需要多少标注才能救回来：

| 新增标注数 | 该类型 R² |
|---:|---:|
| 0 | **0.02**（不可用）|
| **10** | **0.147** |
| 25 | 0.248 |
| 50 | 0.334 |

**关键：必须重训，不能在推理端做平移。**

我们实测过"只估一个偏移量再加回去"的捷径：

| n | 仅偏移校正 | 重训 | 恢复比例 |
|---:|---:|---:|---:|
| 10 | −0.027 | +0.147 | **19%** |
| 25 | +0.023 | +0.248 | **29%** |
| 50 | +0.099 | +0.334 | **42%** |

只恢复 19–42%，因为那个 +0.147 里"组间平移"只是一小部分，其余来自模型重新拟合了该类型的**族内结构斜率**。

## 3b 启动方式与常见报错

### 正确启动

```bash
# 方式一：双击
start.bat

# 方式二：命令行（必须用项目虚拟环境）
cd cpa-peptide      # 仓库根目录
.venv\Scripts\python.exe cpamp_gui.py
```

### 关于 `start.bat`

批处理文件内容为**纯 ASCII**，避免 cmd 按 GBK 解析 UTF-8 中文导致的乱码
（这个坑真实踩过：中文注释被当成命令逐行执行，满屏"不是内部或外部命令"）。

修改它时**请保持纯 ASCII**，或另存为 ANSI（GBK）编码。

### ❌ ModuleNotFoundError: No module named 'lightgbm'

**原因**：用了没有 lightgbm 的 Python 启动。模型文件是 LightGBM 训练的，
`pickle.load` 重建模型对象时必须能 `import lightgbm`，所以一加载模型就崩。

**解决**：改用项目虚拟环境（见上）。界面启动时会自检依赖并弹窗提示。

| 解释器 | lightgbm | rdkit |
|---|---|---|
| 项目 `.venv` | ✅ | ✅ |
| 系统 `python`（商店占位符）| — | — |
| 其他 Python | 需自行安装 | 需自行安装 |

### ❌ 预测很慢 / 像卡住

v8 之前有个性能 bug：读 ESM 缓存时把 `z["emb"][i]` 写在字典推导里，
导致每次迭代都重新解压整个 npz 成员（3,094 次 ≈ **200 秒**）。
现已修复，同一批 12 条从 **198 秒降到 0.7 秒**。

若仍慢，通常是**提供了序列**（`Seq` 列）且该序列不在缓存里 ——
此时会现场跑 ESM-2 模型，首次约 30–60 秒（含模型加载），之后同进程内变快。

### ❌ 定量结果为空（NaN）

**原因**：没填 `Strain`。定量模型需要「菌株上下文」6 维特征
（革兰氏分类 / 菌株编号 / 该株中位 MIC），没有菌株就构造不出来。

**解决**：至少填一个菌株。此时仍会输出定性通道（定性不依赖菌株上下文）。

### ⚠️ ESM 融合为 0/12

输入没有 `Seq` 列（或序列为空）时，ESM 分支无数据可用，
自动回退为「仅主模型」，不影响定量结果（融合权重 w 退化为 0）。

## 4 快速开始

### 4.1 预测

准备一个 CSV（列名大小写不敏感，也支持中文名）：

```csv
SMILES,Strain,cfuGroup,Medium,CyclizationType
CC(C)C[C@@H]1NC(=O)...,Escherichia coli K-12,2,MHB,DSB
```

```bash
python cpamp_tool.py predict -i my_peptides.csv -o result.csv
```

输出列：

| 列 | 含义 |
|---|---|
| `定量_uM` | 预测 MIC（µM）|
| `定量_uM_low90` / `high90` | **90% 预测区间** |
| `σ_log10` | 区间宽度所用的 σ |
| `信赖等级` | 高 / 中 / 低 / 仅定性 |
| `说明` | 逐条理由 |

### 4.2 诊断偏差

拿到一批实测数据后，先别急着重训，先看偏了多少：

```bash
python cpamp_tool.py check -l my_labels.csv
```

输出示例：

```
偏差（实测 − 预测）：均值 +0.62  中位 +0.58  SD 0.31
⇒ 系统性偏差 +0.62 log（约 4.2 倍），建议补标注后重训
```

### 4.3 重训

```bash
python cpamp_tool.py finetune -l my_labels.csv -o my_model.pkl
python cpamp_tool.py predict -i new.csv --base my_model.pkl
```

```bash
python cpamp_tool.py predict -i my_peptides.csv -o result.csv
```

| 列 | 说明 |
|---|---|
| `ID` | 序号（输入里有 ID 列则用它）|
| `定量_uM` | 预测 MIC |
| `定量区间` | 90% 区间，如 `6.14–255` |
| `信赖等级` | 高 / 中 / 低 / 仅定性 |
| `定性_总抗菌` | 概率 |
| `定性_抗细菌` | 概率 |
| `定性_抗革兰阳性` | 概率 |
| `定性_抗革兰阴性` | 概率 |
| `定性_抗真菌` | 概率 |
| **`判定`** | 如 `阳性：总抗菌、革兰阳性、革兰阴性` 或 `阴性` |

需要完整信息（校准阳性率、Wilson 区间、σ、四轴说明）时加 `--detail`：

```bash
python cpamp_tool.py predict -i my_peptides.csv --detail -o full.csv
```

### 判定规则

- 每个目标：**校准阳性率 ≥ 0.5** 判阳性（"更可能阳性"这一可解释的作业点）
- **生物学约束**：`总抗菌 = 抗细菌 ∪ 革兰阳性 ∪ 革兰阴性`
- 汇总成一句 `阳性：…`；若无任何目标达阈值则为 `阴性`

> 为什么不用约登最优阈值判阳：那些阈值是为最大化 Sn+Sp 得到的，
> 多数远低于 0.5（革兰阴性 0.053、抗真菌 0.099），直接拿来判阳会让几乎所有肽都判阳性。
> 约登阈值仍用于报告 Sn/Sp（见 §9b）。

### 输入不需要实测值

预测只需 `SMILES` 一列；`Strain` / `Seq` / `cfuGroup` / `Medium` / `CyclizationType`
都是可选，缺省时对应轴按"未知"处理（会影响区间宽度与信赖等级）。

只有 `check` 与 `finetune` 才需要 `MIC_uM`。

## 5 标注文件格式

必需三列：

| 列 | 说明 |
|---|---|
| `SMILES` | 分子结构（也认 `结构` / `分子`）|
| `Strain` | 菌株名，需与训练集一致（也认 `菌株` / `species`）|
| `MIC_uM` | 实测 MIC，单位 µM（也认 `MIC`）|

强烈建议提供：

| 列 | 说明 |
|---|---|
| `CyclizationType` | 成环化学类型（如 `DSB` / `AMD`）。**这是影响最大的字段** |
| `cfuGroup` | 接种量档 0–4（`<1E4` / `1E4–1E5` / `1E5–1E6` / `1E6–1E7` / `>1E7`）|
| `Medium` | 培养基，如 `MHB` / `CAMHB` |
| `Seq` | 肽序列（单字母）。缺失时序列特征为 0 |

**⚠️ 关于 `CyclizationType`**：不提供时会按"新类型"处理，预测会向训练均值收缩（×0.51），数值偏保守。**这是影响最大的一个字段**，务必填。

## 6 适用域与信赖等级

系统用四根轴判定可信度：

| 轴 | 判据 |
|---|---|
| 菌株 | 是否在 155 株训练集内 |
| 环化类型 | 是否在 18 种训练类型内 |
| 结构 | 与训练集最大 Tanimoto ≥ 0.7 |
| 条件 | 培养基 ∈ {MHB, CAMHB} 且 cfuGroup ∈ {1,2,3} |

全部满足 → **高**；违反 1 项 → 中；≥2 项 → 低；未指定菌株 → **仅定性**。

实测：标准条件下 R² = **0.6928**，非标准条件 R² = **0.6027**。

## 6b 菌株支撑度（重要）

155 个菌株**全部有训练数据**（每株 30–983 对），但**预测能力差异很大**：

| 判定 | 株数 | 占比 | OOF R² 口径 |
|---|---:|---:|---|
| 充分 | 81 | 52.3% | ≥ 0.4 |
| 可用 | 36 | 23.2% | ≥ 0.2 |
| 弱 | 38 | 24.5% | 其余 |
| 其中 R² < 0 | **18** | 11.6% | 不如取均值 |

**系统已按支撑度自动下调信赖等级**：

| 该株判定 | 处理 |
|---|---|
| 充分 | 不变 |
| 可用 | 不变，说明里注明样本量与 R² |
| 弱 | **降 1 级** |
| R² < 0 | **降 2 级**（通常为「低」），说明标注"仅供定性参考" |

界面下拉同样带标签：`Pseudomonas aeruginosa ATCC 27853 · 983对·充分`

详见 [strain_audit.md](strain_audit.md)。

## 7b 实测验证：新成环类型的「标注学习」

把某个成环类型的**全部样本从训练集剔除**，训练一个"盲模型"，再模拟用户拿 10 条标注做重训：

| 留出类型 | 样本数 | 零标注 R² | **+10 标注重训** | Δ |
|---|---:|---:|---:|---:|
| p-XylB | 32 | −0.042 | **+0.678** | +0.720 |
| none | 39 | −0.303 | **+0.438** | +0.740 |
| CLK | 48 | +0.129 | **+0.631** | +0.501 |
| (E)-but-2-enyl-B | 77 | −0.792 | **+0.149** | +0.940 |
| CAR | 49 | −0.085 | +0.136 | +0.221 |
| AMN | 41 | −0.041 | +0.109 | +0.150 |
| TIE | 334 | +0.216 | +0.314 | +0.098 |
| TRZB | 30 | −6.074 | −0.782 | +5.292 |
| **平均** | — | **−0.874** | **+0.209** | **+1.083** |

**8 个留出类型中，7 个从「零或负」变为「正」**，1 个（TRZB，仅 30 样本、中位值极端）大幅改善但仍为负。

> 注意：此处每次只留出**一个**类型，因此绝对数值高于论文中「同时留出全部类型」的 LOCTO 口径（R² ≈ 0.02）。

该验证的逐类型结果见 `docs/` 内的实验记录；
验证脚本属于研究过程代码，未随本仓库发布，复现请联系作者。

## 8 模型结构

```
定量通道
  2,331 维分子描述符（Morgan 2,048 + 环化专属 21 + 拓扑 33 + 其余）
  + cfuGroup 序数（1）+ 缺失标记（1）
  + 菌株上下文 6 维（革兰 4 + 菌株编号 1 + 该株中位 MIC 1）
  = 2,339 维  → LightGBM（600 树，3 seeds）

序列通道
  ESM-2 (t12, 35M, 冻结) mean+max 池化 960 维 + 菌株上下文 6 = 966 维
  → LightGBM（3 seeds）

融合：p = 0.65 × p_主 + 0.35 × p_ESM
校准：成环类型未见过 → × 0.51（预注册值，非测试集调参）
区间：10^(ŷ ± 1.645 σ)，σ 按（新颖度 × 条件）查表
```

> **注**：2,331 维中有 584 列是常数（573 个 Morgan 位从未在 3,828 条肽中出现 + 8 个拓扑列 + 3 个环化列），
> 另前 31 列（序列统计 / 氨基酸组成 / 理化）因早期序列数据不可靠而置零。

## 9b 双通道输出与两种「不确定度」

系统同时输出**定量**与**定性**两个通道，但两者的不确定度**含义不同，不可互换**。

| | 定量通道 | 定性通道 |
|---|---|---|
| 输出 | MIC（µM）+ 90% 区间 | 5 类活性概率 + 校准阳性率 + 可靠度 |
| 不确定度是什么 | **预测误差的尺度**（回归残差 SD）| **概率的可靠性**（该分数段的实测阳性率）|
| 依据 | σ 查表（新颖度 × 测定条件）| OOF 分箱 + Wilson 95% 二项区间 |
| 能否叫「置信区间」| 是（预测区间）| 否（是可靠性区间）|

### 为什么不能给定性也套一个 σ

σ 标在 `log10(MIC)` 上，是回归残差的尺度。定性输出是**概率**，量纲与语义都不同，
把 σ 直接套上去没有意义。

### 定性通道给的是「这个概率有多可信」

| 概率 p | 该分数段的实测阳性率 | Wilson 95% | 可靠度 |
|---:|---:|---|---|
| 0.01 | 0.047 | [0.034, 0.065] | 高 |
| 0.85 | 0.488 | [0.346, 0.632] | 不确定（跨 0.5）|
| 0.99 | 0.948 | [0.925, 0.964] | 高 |

（上表为「抗细菌」目标，n = 1 405）

**读法**：模型给出 0.85 时，历史上这一分数段的实际阳性率只有 48.8%（区间跨 0.5），
因此**不应据此判阳性**；而给出 0.99 时实际阳性率 94.8%，可用。

### 可靠度分级

| 等级 | 判据 |
|---|---|
| 高 | Wilson 区间宽度 < 0.10 且不跨 0.5 |
| 中 | 宽度 < 0.25 |
| 低 | 宽度 ≥ 0.25 |
| **不确定** | **区间跨 0.5 —— 不宜据此判定** |

### 判定阈值

用**约登指数**在 OOF 上定，不是固定 0.5：

| 目标 | 最优阈值 | 该阈值下 Sn | Sp |
|---|---:|---:|---:|
| 总抗菌 | 0.817 | 0.871 | 0.960 |
| 抗细菌 | 0.494 | 0.898 | 0.921 |
| 抗革兰阳性 | 0.179 | 0.939 | 0.866 |
| 抗革兰阴性 | 0.053 | 0.966 | 0.829 |
| 抗真菌 | 0.099 | 0.870 | 0.786 |

**注意这些阈值离 0.5 很远** —— 说明模型概率的绝对标定不佳（虽然排序 AUROC 0.89–0.95 很好）。
这正是需要「校准阳性率」而不是「原始概率」的原因。

### 输出列

```
定量通道
  定量_log10uM / 定量_uM          点预测
  定量_uM_low90 / high90          90% 区间
  σ_log10                         区间宽度
  信赖等级                        高/中/低/仅定性（四轴）

定性通道
  定性_<目标>                     5 个概率
  定性_<目标>_校准                实测阳性率 [Wilson 95%] (n=…)
  定性_<目标>_可靠度              高/中/低/不确定
  定性判定 / 定性判定阈值          按约登阈值
  区间说明                        两种不确定度的区别
```

## 10 已知限制

| 限制 | 说明 |
|---|---|
| 新成环化学零标注不可用 | R² ≈ 0.02，必须补标注 |
| 全新肽骨架无支撑 | 未见过的新肽 R² = −0.11；化学冗余极高（近邻 Tanimoto 中位 0.958）|
| 跨菌株的菌株特异分量大部分不可学 | 表观菌株间方差 0.427 中，重复测定噪声占 0.407 |
| 条件字段不能提精度 | cfu 对同分布 +0.0040，对未见环化 −0.0022 |
| 区间基于正态假设 | 重尾时可能偏窄 |
